## Research experience

**Graduate Research Assistant · COMPAS Lab, Stony Brook University**  
Jan 2025–Present

- **Isochrone | Quantum data center research**: Developed a simulator and scheduling prototype for hybrid quantum-classical workloads. Modeled task dependencies and placement across CPUs and quantum processors to study queuing and job completion time. Used sample-based quantum diagonalization (SQD) as a validation workload and benchmarked its classical processing with fixed inputs across CPU configurations.
- **NeoMantis** — Built the coordinator CLI for job submission, scaling, and cluster management. Ran MetaGraph baseline experiments for the distributed sequence index.
- **MPSP** — Ported Node.js and Memcached to RISC-V SIMT cores using fiber-based parallelism. Contributed fixes across musl, QEMU, and kernel support.

**Researcher · HPCAN Lab, Sharif University of Technology**  
Oct 2020–Feb 2024

- Studied GPU memory access latency and L2 cache efficiency. Built an ISCAS circuit parser and simulator and mentored junior researchers.
